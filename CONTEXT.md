# Content context

**Entry** is any published piece a reader can open. Every Entry uses the same canonical route and reading layout.

**Series** is a durable thread of Entries around one ongoing question, project, or learning path. Its stable identifier lives in entry frontmatter.

**Tag** is a cross-cutting index term. It does not imply reading order or membership in a single thread.

**Source collection** is the authoring location that supplies optional metadata. It is not a public page type.
